# Valise — iOS апликација за паметно пакување

Верзија 1.1: изглед „карта за прва класа“, македонски / English, прогноза за сите денови (лани = *), освежување при секое отворање, споделување на Instagram Story.

Верзија 1.2: прво избор на јазик, календар со еден допир за поаѓање и враќање, сопатници (кој што носи), побрз Story без багаж/спакувано.

Верзија 1.3: екранот не шета лево-десно, нов календар (автоматски враќање, брзи траења), Уреди патување, избирач „кој носи“ на заедничките предмети.

Верзија 1.4: почетна со пасови во мрежа, Story со повеќе слики (допир за следна) и сопствена слика, Premium теми (Ривиера роза, Лаванда, Смарагд, Ноар, Азурна обала).

Верзија 1.5: акаунти преку Firebase (е-пошта), синхронизација на патувањата, сопатници од контакти со препознавање дали имаат акаунт, покани што чекаат, заедничко штиклирање.

Верзија 1.6: најава со Google.

Верзија 1.7: слики без луѓе (проверка на телефонот), лична листа + дел „Заедно“ (кој што носи, синхронизирано), почеток јазик → име → акаунт, теми Машнички и Цветна.

Верзија 1.8: Гардероба — облека како стикери (сликај → исечи, лицата никогаш не се зачувуваат), сезони пролет/лето/есен/зима, аутфити, план „што облекувам“ за секој ден од патувањето со порака кога нешто се повторува, облеката од аутфитите во листата за пакување.

Верзија 1.9: повеќе аутфити во еден ден, „Облека за патувањето“ (колку парчиња, што се повторува ×N, дали собира во куферот + предупредување), бројач и порака во составувачот, избор стикер или исечена слика, 7 нови теми (Балерина, Јагодово млеко, Цреши, Матча, Ванила латте, Пеперутки, Ѕвездена ноќ).

Верзија 2.0: гардеробата, аутфитите и планот по денови се чуваат на акаунтот (Firestore, само за сопственикот) — по одјава и повторна најава или на нов телефон сè се враќа; „Облека од аутфитите“ веднаш под „Облека“ со број по категории и „Усогласи ја облеката“.

Верзија 2.1: акаунтот е задолжителен; при одјава сè се брише од телефонот (останува на акаунтот и се враќа при најава); бројките за облека во листата (маици 5, панталони 2, обувки…) се споредуваат постојано со аутфитите — „Од аутфитите 3/5“ и предупредувања кога фали; сигурни слики за Story (до 8, секогаш истите, повеќе извори, дизајнирани позадини); побрза гардероба (мали сликички, брзо пребарување).

Верзија 2.2: подготовка за App Store — Најава со Apple (се вклучува со платена сметка), PrivacyInfo.xcprivacy, ITSAppUsesNonExemptEncryption, тест-отклучување само надвор од App Store, целосно бришење на профилот, автор и лиценца на фотографиите од Wikimedia, iPhone Duo/iPad (сите насоки на голем екран), Liquid Glass таб-лента на iOS 26+, VoiceOver ознаки, градење со најнов Xcode (27.x) на macOS 26.

Верзија 2.3: 140+ авиокомпании од целиот свет со пребарување (име, IATA код, земја), повеќе багажи по патување (со бројач), бројка од аутфитите до планираното во листата (×6) и предупредување кога се надминува, почетна со „Ново патување“ прва и филтер Претстојни / Поминати / Сите.

Верзија 2.4: нова икона — куфер нацртан со тенкопишувач и маркер, со црвена етикета „V“; посебни верзии за темен и обоен (tinted) изглед на почетниот екран (iOS 18+).
Заедно: кога ќе штиклираш заедничка работа што била за некој друг (пр. Виктор), таа станува твоја — кај сите пишува дека ја носиш ти.

Верзија 2.5 (закони и правила): Политика за приватност и Услови за користење во апликацијата (Поставки → Приватност и услови, и при регистрација); неутрално прашање за датум на раѓање пред регистрација (под 13 години — нема акаунт, ништо не се чува); профилите во Firestore ги чита само сопственикот; прогноза од Apple Weather (WeatherKit) и пребарување места со Apple Maps во App Store верзијата, со задолжителниот потпис на изворот.

## TestFlight (официјално тестирање) — без Mac
Workflow-от `.github/workflows/testflight.yml` прави архива, ја потпишува преку App Store Connect API клучот и ја качува на TestFlight. Тест-верзијата за Sideloadly (`build-ipa.yml`) останува иста.

**Еднаш:**
1. developer.apple.com → **Certificates, IDs & Profiles → Identifiers → +** → App IDs → App → Bundle ID `com.valise.packing` (Explicit). Вклучи **Sign in with Apple**, а во *App Services* — **WeatherKit**.
2. appstoreconnect.apple.com → **Apps → + → New App**: iOS, име (привремено), Primary Language, Bundle ID `com.valise.packing`, SKU `valise001`.
3. App Store Connect → **Users and Access → Integrations → App Store Connect API → Team Keys → +** → име `GitHub`, улога **Admin** → Generate. Симни го `.p8` (може само еднаш), запиши **Key ID** и **Issuer ID**.
4. developer.apple.com → **Account → Membership details** → **Team ID**.
5. GitHub репото → **Settings → Secrets and variables → Actions → New repository secret**: `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (целата содржина на .p8, отворен со Notepad).
6. Firebase → Authentication → Sign-in method → **Apple** → Enable.

**Секое качување:** GitHub → **Actions → „Качи на TestFlight“ → Run workflow**. За 10–30 минути изградбата е во App Store Connect → TestFlight. Бројот на изградбата се зголемува сам.

Во TestFlight изградбата се вклучени Најава со Apple и Apple Weather (`VALISE_STORE_BUILD = YES`). Во Sideloadly изградбата — исклучени (Open-Meteo).

## Пред App Store
1. App Store Connect → In-App Purchase `com.valise.premium.lifetime` (Non-Consumable) и **Agreements, Tax, and Banking → Paid Apps**.
2. Види `LEGAL-CHECKLIST.md` — линкови, приватност, возраст, статус на трговец.

**Важно за 2.0:** во Firebase → Firestore → Rules залепи го новиот `firestore.rules` и притисни Publish.

## Firebase (еднаш)
1. Firebase Console → проектот `valise-76aa0`.
2. **Authentication → Sign-in method → Email/Password и Google → Enable**.
3. **Firestore Database → Create database** (Production mode, локација `eur3`).
4. **Firestore → Rules** → залепи го `firestore.rules` од ова repo → **Publish**.

GitHub автоматски гради `Valise.ipa` при секое качување на код (таб **Actions**).

## Добивање на .ipa
1. Таб **Actions** → последната изградба „Изгради IPA“ (зелена ✓).
2. Долу кај **Artifacts** → **Valise-ipa** → се симнува zip.
3. Отпакувај → `Valise.ipa` → повлечи во Sideloadly.

Рачно повторно градење: Actions → „Изгради IPA“ → **Run workflow**.

Ако изградбата падне (црвено ✗), отвори ја — грешките се прикажани на врвот, во делот *Грешки при изградба*.

## Структура
- `Sources/` — Swift код (екрани во `Sources/Views/`, гардероба во `Sources/Wardrobe/` и `Sources/Views/Wardrobe/`)
- `Assets.xcassets/` — иконата и акцентната боја
- `project.yml` — поставки за проектот (XcodeGen)
- `.github/workflows/build-ipa.yml` — автоматската изградба
